Clara Core Documentation
========================

**Integrate Clara into your life.** An autonomous AI agent framework for personal workflow and workspace automation.

Clara is designed to seamlessly orchestrate daily productivity tasks across communication platforms, calendars, document stores, and external APIs using cognitive agent loops and large language models.
